# Design

Operate mode. Warm paper background, deep forest green text and controls, restrained lime accents, serif emphasis in the main headline. Information-first scholarship cards with distinct textual trust indicators. Profile form on a white panel; desktop split layout becomes a single column on mobile. Persistent demo/live badge. Core controls have keyboard focus states; motion respects reduced-motion. No external fonts or imagery required for offline demo operation. System sans for interface text and Georgia for editorial emphasis.
